# Netflix Content Rating Analysis

## Project Overview
This project analyzes Netflix movies and series using ratings from IMDb, Rotten Tomatoes, and Metacritic to understand audience and critic preferences.

## Dataset
- 15,480 Netflix titles
- Ratings from IMDb (audience), Rotten Tomatoes, and Metacritic (critics)

## Tools Used
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- GitHub

## Key Analysis Performed
- Data cleaning and preprocessing
- IMDb rating distribution analysis
- Genre-wise average rating comparison
- Audience vs critic rating correlation
- Movies vs series performance comparison

## Key Insights
- IMDb ratings follow a near-normal distribution, with most titles rated between 5.5 and 7.5.
- Critics (Rotten Tomatoes and Metacritic) show very strong agreement (correlation ≈ 0.90).
- Audience ratings show moderate agreement with critics, indicating perception differences.
- Series have higher average IMDb ratings than movies, suggesting stronger audience engagement.

## Conclusion
The analysis highlights differences between audience and critic perception and shows that long-form content performs better on Netflix.
